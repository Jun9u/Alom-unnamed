# 데이터 보관 안내

이 저장소에는 실제 음성, 개인정보, 학습 데이터와 모델 가중치를 넣지 않습니다.
이 폴더는 README를 제외하고 Git 추적에서 제외됩니다.
데이터는 팀이 합의한 별도 접근제한 경로에 보관합니다.

데이터 이용 조건에서 팀 내 공유, 외부 API 전송, 서비스 활용, 보관·삭제를 각각 확인합니다.
공개 데이터라고 해서 외부 음성 API에 전송할 권한까지 있다고 가정하지 않습니다.
음성 전사와 발음 오류 정답은 다릅니다. 라벨 구조를 확인하기 전까지 학습 가능성을 단정하지 않습니다.

Git 추적 제외와 저장소 검사 도구는 실수 방지 장치일 뿐 완전한 보안 검사가 아닙니다.
키가 노출되면 파일 삭제만 하지 말고 해당 키를 폐기·재발급합니다.
