# 실험

코드와 개인정보 없는 요약만 올립니다. 실제 녹음과 원시 응답은 승인된 로컬 경로에 둡니다.
모델·서비스명, 버전·설정, 입력 조건, 처리 시간, 실패 상태, 관찰 결과를 기록합니다.
첫 목표는 짧은 한국어 예문 한 건의 실제 분석 결과 확보입니다.
모델 선정이나 자체 학습은 그 결과를 확인한 뒤 결정합니다.

`azure_pronunciation_smoke.py`의 선택적 의존성, 오프라인 테스트, 나중에 실행할
마이크 실험 명령은 [AI 안내](../README.md)에 있습니다. 저장소 루트에서 `-m`으로
실행하며, `.env`를 읽지 않고 `--call-azure`를 지정할 때만 실제 호출을 진행합니다.
