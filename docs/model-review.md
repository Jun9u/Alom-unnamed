음성인식(STT: Speech-to-Text)은 실제 발화를 텍스트로 바꾸는 작업입니다.
텍스트가 맞았다는 사실을 발음 정확도로 해석하지 않습니다.
위 표를 채운 다음 작은 비교 실험을 구성하며, 실제 사용자의 적합성 검증은 별도로 수행합니다.
