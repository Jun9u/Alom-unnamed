# 연결 구조 초안

클라이언트 녹음 → 백엔드 요청 수신 → 분석 도구 → 백엔드 결과 정리 → 클라이언트 표시

모델 검증 전에는 외부 API와 자체 Python 서비스 중 어느 방식도 확정하지 않습니다.
화면·백엔드는 공통 예시 응답으로 먼저 연결하고, 실제 분석기로 바꿀 수 있게 합니다.

## 파트 간 합의가 필요한 항목

| 항목 | 결정 상태 |
|---|---|
| 녹음 파일 형식·최대 길이·크기 | 미정 |
| 목표 예문 식별자와 요청 형식 | 미정 |
| 분석 중·성공·실패·불확실 상태 | 미정 |
| 지원되는 결과 필드와 근거 표시 | 실제 분석 결과 확인 후 결정 |
| 원본 저장·삭제·외부 전송 동의 | 미정 |
| API 호출 예산과 계정 소유 | 미정 |

분석 실패를 점수 0으로 표시하지 않습니다. 현재 문서는 API 명세 확정본이 아닙니다.
